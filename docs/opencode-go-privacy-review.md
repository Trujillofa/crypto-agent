# OpenCode Go sentiment fallback review

Reviewed 2026-11-03. This is a point-in-time policy assessment, not a continuing guarantee. Recheck provider terms and workspace settings before enabling or deploying this route.

* [Go privacy table and usage terms](https://opencode.ai/v2/docs/console/go): `beam-free` is listed as not used for training, with 30-day retention. `iceman-contributor-free` is used for model improvement and is not ZDR. The Go list is not the same as the [Console free model list](https://opencode.ai/v2/docs/console/models); do not infer Go approval from Console model names.
* The same Go documentation says the service is designed for coding agents and clients should send typical coding agent traffic, identify their own user agent, and send a stable session ID per conversation. Sentiment analysis is not typical coding agent traffic. **Do not enable/deploy this use without resolving provider suitability/permission.** The route probe below does not establish permission for sentiment traffic.
* The Go privacy table lists paid `glm-5.3-flash` as no training, zero days. It lists `deepseek-v4.1-flash` similarly, but explicitly says its ZDR agreement was valid only through 2026-10-31 and is renewed monthly; current protection is unverified. DeepSeek also requires enabling the Global region. Paid Go fallback is intentionally not added: usage may incur charges and current DeepSeek privacy is unverified.
* A synthetic coding-only probe against the configured Go endpoint and existing key on 2026-11-03 advertised all three models. `beam-free` and `glm-5.3-flash` returned HTTP success and nonempty content; `deepseek-v4.1-flash` returned HTTP success but no content with an 80-token limit. No trading data or orders were used. A successful HTTP response does not prove sentiment output validity, future availability, or permission.
* The reviewed free selector uses an exact allowlist intersected with the live Go catalog, refreshed daily, and fails closed when empty. `beam-free` retention is **not** zero; accepting its 30-day retention requires an explicit operational privacy decision. Catalog metadata alone does not prove current privacy policy. Review the allowlist when policy, availability, or intended use changes.
